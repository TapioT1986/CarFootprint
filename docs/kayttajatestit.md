# CarFootprint – käyttäjätestit

Lyhyt ohje, jolla voit testata laskuria muutamalla ihmisellä. Tavoite on nähdä, **missä ihmiset jumittuvat**, ei kysyä mielipiteitä.
Yksi testi kestää 15–20 minuuttia.

## Ketä ja kuinka monta

- **5 henkilöä riittää.** Viisi testaajaa löytää tutkimusten mukaan suurimman osan käytettävyysongelmista
  ([Nielsen Norman Group: Why You Only Need to Test with 5 Users](https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/)).
  Kolmekin auttaa.
- Mieluiten ihmisiä, jotka **eivät ole nähneet laskuria** ja jotka ovat joskus miettineet auton ostoa. Sekaan yksi, joka ei ole
  kiinnostunut autoista eikä tekniikasta.
- Ainakin osa **puhelimella**, koska useimmat avaavat sivun sillä.

## Valmistelu

1. Avaa https://tapiot1986.github.io/CarFootprint/ testaajan laitteella **yksityisessä ikkunassa** (incognito), jotta aiemmat
   tallennukset eivät näy.
2. Pidä paperi tai puhelimen muistio valmiina. **Älä kirjoita muistiin testaajan nimeä.** Kysy lupa muistiinpanoihin.
3. Sano testaajalle suunnilleen näin:
   > "Testaamme laskuria, emme sinua. Et voi tehdä mitään väärin. Ajattele ääneen: kerro, mitä etsit, mitä luulet tapahtuvan
   > ja mikä hämmentää. En auta, koska haluan nähdä, missä laskuri ei auta sinua itse."

## Tehtävät

Lue tehtävä ääneen tai anna se paperilla. **Älä näytä tai neuvo.** Jos testaaja jumittuu yli kahdeksi minuutiksi, sano
"siirrytään seuraavaan" ja kirjaa kohta.

1. **Ensivaikutelma (30 sekuntia):** "Katso sivua puoli minuuttia koskematta mihinkään. Mitä tällä sivulla voi tehdä?
   Kenelle se on tehty?"
2. **Oma tilanne:** "Ajat noin 15 000 km vuodessa. Selvitä, paljonko käytetty Toyota Corolla -hybridi maksaisi sinulle
   vuodessa ja kuukaudessa."
3. **Vertailu:** "Vertaa sitä sähköautoon, esimerkiksi Tesla Model 3:een. Kumpi on halvempi ja miksi? Kumpi päästää vähemmän?"
4. **Oma auto:** "Kuvittele, että nykyinen autosi on jokin listan autoista. Merkitse se nykyiseksi autoksesi ja selvitä,
   kannattaisiko vaihtaa johonkin toiseen."
5. **Luottamus:** "Mistä vuosikulun arvonalenema tai vakuutuksen hinta tulee? Luotatko lukuun?"
6. **Jakaminen:** "Lähetä tämä vertailu puolisolle tai kaverille."

## Mitä kirjataan (jokaisesta tehtävästä)

| Tehtävä | Onnistui itse / avulla / ei | Aika noin | Missä jumittui tai mitä etsi | Suora lainaus |
| --- | --- | --- | --- | --- |
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |
| 6 | | | | |

Kirjaa erityisesti:
- kohdat, joissa testaaja **etsi jotain eikä löytänyt** (mitä hän etsi ja mistä)
- sanat tai luvut, joita hän **ei ymmärtänyt**
- kohdat, joissa hän **epäili lukua**
- mitä hän **ohitti** (esim. ei avannut lisätietoja, ei huomannut tuloskorttia)

## Loppukysymykset (2–3 minuuttia)

1. "Mikä oli vaikeinta?"
2. "Puuttuiko jotain, mitä olisit halunnut tietää autosta?"
3. "Käyttäisitkö tätä, jos ostaisit oikeasti auton? Miksi tai miksi et?"
4. "Asteikolla 1–5, kuinka helppo laskuria oli käyttää?" (1 = hyvin vaikea, 5 = hyvin helppo)

## Testin jälkeen

Lähetä muistiinpanot Claudelle CarFootprint-istuntoon (kirjoita tai ota kuva paperista). Ilman nimiä. Claude kokoaa niistä
yhteenvedon: mitkä ongelmat toistuivat useammalla testaajalla, ja ehdottaa korjaukset tärkeysjärjestyksessä.
